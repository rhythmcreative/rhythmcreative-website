Como

La pagina

HTML, CSS y JavaScript a pelo. Sin build, sin framework y sin dependencias. Se abre haciendo doble clic en index.html y tambien se sirve desde GitHub Pages tal cual.

Los datos van en ficheros .js y no en .json a proposito: un fetch de un JSON local desde file:// lo bloquea el navegador.

Anadir un proyecto

Se edita assets/projects.js y se anade un objeto al array. Con repo mise, el name y la frase, la tarjeta sale sola con los datos en vivo.

La API de GitHub sin token da 60 peticiones por hora. Con este numero de repos sobra, y si algun dia se queda corta la pagina lo dice y enseña el valor guardado en vez de quedarse en blanco.

El tema vivo

El tema Pywal no esta escrito a mano: sale de ~/.cache/wal/colors.json, los mismos colores que tiñen la barra y la isla. Cambia el fondo de pantalla y cambia aqui.

T siguiente, Shift+T el anterior, y se recuerda en localStorage.
